Privacy policy

Last updated 18 November 2026.

WikiShorts Uploader is a small tool that uploads videos to the PepperYaps YouTube channel. Only the channel's owner uses it. It has no other users.

YouTube API Services

WikiShorts Uploader uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is covered by the Google Privacy Policy.

Its use of information from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

What it accesses and keeps

  • It uploads the owner's own videos to the owner's channel and reads the channel's name and ID.
  • It keeps one sign-in token, on the owner's own computer. Nothing is sent to any server other than Google's.
  • It does not collect, store or share data about viewers or anyone else.

Removing access and deleting data

  • Access can be removed at any time on the Google security settings page.
  • Deleting the token file from the owner's computer deletes all data the tool keeps. It is also deleted within 7 days if access is removed.
